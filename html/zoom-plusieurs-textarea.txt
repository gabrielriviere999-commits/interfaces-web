## 🎯 1) Changer le font‑size de **tous les textarea**

```js
function applyZoomAll() {
    var size = document.getElementById("zoomRange").value;
    var list = document.getElementsByTagName("textarea");

    for (var i = 0; i < list.length; i++) {
        list[i].style.fontSize = size + "px";
    }
}
```

Et ton slider :

```html
<input id="zoomRange" type="range" min="6" max="40" value="12" oninput="applyZoomAll()">
```

👉 Simple, global, efficace.

## 🎯 4) Bouton “Reset zoom” pour plusieurs textarea

```js
function resetZoom() {
    var defaultSize = 12;
    var slider = document.getElementById("zoomRange");
    slider.value = defaultSize;

    // appliquer à tous les textarea
    var list = document.getElementsByTagName("textarea");
    for (var i = 0; i < list.length; i++) {
        list[i].style.fontSize = defaultSize + "px";
    }
}
```

HTML :

```html
<button onclick="resetZoom()">Reset zoom</button>
```
